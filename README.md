# Timdoc

Локальное Windows-приложение, которое читает PDF-акт и создает для каждой единицы
техники отдельные `Талон.docx`, `Форма 4.docx` и `Форма 11.docx`. Готовый комплект
также сохраняется одним ZIP-архивом.

## Что требуется на компьютере

- Windows 10 или 11;
- Microsoft Word;
- Microsoft Edge WebView2, он уже входит в актуальные Windows 10/11;
- PDF-акт с текстовым слоем;
- папка с исходными шаблонами.

Данные никуда не отправляются. Справочник хозяйств, настройки и журнал операций
лежат в `%LOCALAPPDATA%\Timdoc`. Исходные шаблоны приложение не изменяет.

## Работа в приложении

1. Запустите `Timdoc.exe`.
2. Откройте «Настройки», выберите папку исходных шаблонов и проверьте данные
   сервисного центра. По умолчанию: `ООО «Акрос РБ»`, `Инженер`,
   `Абдрахманов Т.М.`.
3. Нажмите «Выбрать файл акта» и укажите PDF.
4. Проверьте хозяйство, ИНН, адрес и список техники. ИНН обязателен.
5. Выберите папку сохранения и нажмите «Создать документы».

Поля, которые подписывают от руки, остаются пустыми: дата составления Форм 4 и 11,
контактное лицо потребителя, дата постановки на гарантийный учёт в талоне, подпись
представителя потребителя.

Для каждого заводского номера создается отдельная папка с тремя DOCX. Рядом
создается ZIP со всем комплектом. Повторная генерация не перезаписывает прежний
результат, а добавляет номер к имени нового комплекта.

## Ограничение первой версии

Скан без текстового слоя не распознается. Приложение сообщит, что OCR пока не
поддерживается. Старые шаблоны `.doc` (талон, Форма 4, Форма 11) автоматически преобразуются
через Word при первом выборе папки шаблонов.

## Разработка

```powershell
uv sync --all-packages --extra desktop --extra dev --extra build
uv run timdoc
```

На macOS приложение тоже запускается: старые `.doc` преобразует установленный Word
для Mac (через AppleScript, внутри его собственной папки, без диалогов доступа).
Приемка на реальных шаблонах: положите папку `doc_templates` рядом (она не хранится в
Git) или укажите её в `TIMDOC_TEMPLATES`, затем `uv run pytest -m eval --no-cov`.

Проверки:

```powershell
uv run ruff check .
uv run ruff format --check .
uv run mypy src contracts/src services/act-parser/src services/customer-store/src services/document-generator/src
uv run pytest
uv run pytest -m eval --no-cov
node --check src/timdoc_app/ui/app.js
```

## Сборка Windows

```powershell
uv run pyinstaller packaging/timdoc.spec --clean --noconfirm
dist\Timdoc\Timdoc.exe --self-test
```

GitHub Actions собирает переносимую ZIP-папку и установщик. Бинарные файлы в Git
не добавляются.
